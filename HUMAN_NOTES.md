## Debugging

In one terminal run: `bun run dev:http`
In another terminal run: `bunx @modelcontextprotocol/inspector`
Use `localcan` to open run a tunnel, and create a public URL that clients can connect to.

Clients will need to pass a `Bearer ...` token that is a Platform API Acccess token.
